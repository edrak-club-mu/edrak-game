# لعبة أوجد الاختلافات — نادي إدراك

إصدار مطوّر من اللعبة يتضمن:
- واجهة أخف وأكثر هدوءًا باستخدام ألوان هوية نادي إدراك.
- مشاهد مرسومة بتفاصيل أكثر واقعية بدل الرسوم البسيطة السابقة.
- مستويين كاملين، ٨ اختلافات في كل مستوى.
- الانتقال من المستوى الأول إلى الثاني مع استمرار النقاط.
- ٦٠ ثانية لكل مستوى + مكافأة للوقت المتبقي.
- يعمل مباشرة من المتصفح بدون سيرفر أو قاعدة بيانات.

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## الملفات
- `index.html`: الواجهات والشاشات.
- `style.css`: التصميم والألوان والاستجابة للشاشات.
- `script.js`: منطق المستويين والاختلافات والمؤقت والنقاط.
- `assets/logo.png`: شعار النادي.
